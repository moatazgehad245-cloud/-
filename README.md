# الفارس العربي — موقع تعريفي تفاعلي

## الملفات
- `index.html` — بنية الموقع بالعربية وRTL.
- `style.css` — الهوية البصرية والتجاوب مع الهاتف.
- `script.js` — مشهد حصان ثلاثي الأبعاد باستخدام Three.js، القائمة، ونموذج طلب عرض السعر.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث مع اتصال بالإنترنت.
3. للحصول على أفضل تجربة، ارفع الملفات الثلاثة إلى GitHub Pages أو استضافة HTTPS.

## قبل النشر الفعلي
- استبدل رقم واتساب التجريبي `201000000000` داخل `script.js` برقم النشاط مع مفتاح الدولة، بدون `+`.
- استبدل البريد التجريبي `hello@example.com` في `index.html`.
- استبدل صور Unsplash بصور حقيقية من شغل المحل بعد امتلاك حق استخدامها.
- أضف الأسعار النهائية، وسياسة القياس والشحن والجمارك والاستبدال.
- نموذج الطلب يفتح واتساب برسالة جاهزة؛ لا يحفظ الطلبات في قاعدة بيانات حاليًا.

## ملاحظة تقنية
الحصان الحالي مشهد ثلاثي الأبعاد مبني برمجيًا من مجسمات Three.js مع حركة وتفاعل خفيف مع حركة المؤشر. للحصول على حصان واقعي سينمائي أكثر، يمكن لاحقًا استبداله بملف 3D أصلي بصيغة GLB/GLTF مرخص للاستخدام.
